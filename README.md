# LikeMovies - AWS Deployment Project

## Overview
This project demonstrates deploying an ASP.NET MVC web application on AWS cloud infrastructure.

## Architecture
- EC2 (Windows Server + IIS)
- RDS (SQL Server)
- Application Load Balancer (ALB)
- Auto Scaling Group (ASG)

## Features
- Deploy ASP.NET MVC on IIS
- Connect EC2 to RDS
- Load balancing with ALB
- Auto scaling based on CPU
